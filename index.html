Static · Fast · No JavaScript

A clean starting point for your next site.

This is an example website made of nothing but HTML and CSS. Drop it behind nginx, point the root at this directory, and it just works — no build step, no dependencies, no runtime.

What's included

Everything below is plain markup and a single stylesheet.

⚡

Zero dependencies

No frameworks, no bundler, no package manager. Edit a file, refresh the page, done.

📐

Responsive layout

CSS grid and flexbox handle everything from a phone to an ultrawide monitor.

🌗

Light & dark

Colors are driven by custom properties and follow the visitor's system theme.

♿

Accessible defaults

Semantic landmarks, a skip link, visible focus rings, and readable contrast.

🧩

Reusable pieces

Cards, buttons, a nav bar, a form, and a footer you can copy anywhere.

📦

Deploy anywhere

It's just files. Serve it from nginx, a CDN, or a USB stick if you like.

Built for the simplest possible hosting

Every page is a self-contained document. There is no server-side rendering, no API to keep alive, and nothing to restart after a deploy. Copy the directory, reload nginx, and the new version is live.

  • Three pages plus a 404, sharing one stylesheet
  • Relative links throughout, so it works from any path
  • Mobile menu built with a checkbox — still no JavaScript
  • About 32 KB total, uncompressed
