About

A little context

Meridian is a placeholder. The words are filler, but the markup and styles are real and meant to be reused.

Why static?

A static site is the least fragile thing you can put on the internet. There's no process to crash, no database to migrate, and no dependency tree to audit. nginx reads a file off disk and sends it — that path has been fast and stable for two decades.

It's also the easiest thing to hand off. Anyone who can read HTML can change a headline, and there's no way to break the build, because there isn't one.

How it's put together

Three HTML documents share css/styles.css. The stylesheet opens with a block of custom properties — colors, spacing, radii, and shadows — so most visual changes are a one-line edit near the top of the file.

Layout uses CSS grid for the card sections and flexbox for the header and footer. The mobile menu is a hidden checkbox paired with a label, which is why the whole site still works with JavaScript disabled.

Making it yours

  1. Edit the --brand and --bg variables in the stylesheet.
  2. Replace the copy on each page.
  3. Swap the ◆ brand mark for a logo image if you have one.
  4. Point nginx at this directory and reload.
